# Заранее посчитанные примеры

Источник **текущих** формул: `src/lib/erp/costing.ts` и тест `burger costing: food vs packaging, VAT, commission, incomplete marking` в `scripts/erp/test-erp.ts`.

Это **не** спецификация Poster. Когда Agent 1/3 зафиксируют другую базу цены (последняя партия / FIFO остатка / справочная), числа пересчитываем и помечаем расхождение.

## Poster vs ERP (спека Товары, 2026-11-06)

Документация Poster «подтверждено документацией», не проверяли на заполненном списке:

- Себестоимость товара/ингредиента = **средневзвешенная** по складу. В карточке вручную не задают.
- Нет поставок → Poster показывает **0**. У нас инвариант брифа: unknown = `null`, никогда 0. На приёмке ждём «неполная / —», не ноль.
- Фудкост Poster = себестоимость / итоговая цена × 100%.
- Наценка Poster: налог выкл `(Цена/Себес − 1)×100`; НДС `(Цена без налога/Себес − 1)×100`.

Наша `markupPct = (netRevenue − totalCost) / totalCost × 100` близка к формуле с НДС. `foodCostPct` у нас от **netRevenue**, у Poster фудкост от итоговой цены — **зазор**, не подгонять без решения.

Списание склада по-прежнему FIFO (`erp_consume`), не средняя Poster.

Правила, которые уже нельзя нарушать:

- Неизвестная стоимость = `null`, никогда `0`.
- Неполный расчёт: `complete=false`, итоги группы `null`.
- Маржа (комментарий в UI): цена без НДС − комиссия канала − продукты − упаковка. Зарплата и аренда не входят.
- Проценты Food Cost / маржи — от цены **без НДС**.
- НДС выходной: `net = price / (1 + vatRate/100)`, если выходной НДС включён.
- Комиссия: `price * commission_pct / 100` (от цены меню, не от net).
- Списание склада — FIFO по партиям (`erp_consume`), не средняя из «Остатков».

## Пример C1–C6. Бургер в тесте

Состав котлеты (рецепт, выход **6** шт):

| Компонент | Кол-во | Цена за ед. | Сумма |
|-----------|--------|-------------|-------|
| Говядина | 1 кг | 300 000 ₫ | 300 000 |
| Соль | 0,01 кг | 10 000 ₫ | 100 |
| **Выход** | 6 шт | | **300 100** |

Себес 1 котлеты = `300100 / 6` = **50 016,666… ₫** (источник `recipe`).

Порция блюда:

| Строка | Кол-во | Себес | Тип |
|--------|--------|-------|-----|
| Котлета | 1 | 50 016,666… | еда |
| Булка | 1 | 10 000 | еда |
| Коробка | 1 | 2 000 | упаковка |

- `foodCost` = **60 016,666…**
- `packagingCost` = **2 000**
- `totalCost` = **62 016,666…**
- Без цены коробки: `packagingCost=null`, `totalCost=null`, `missing` содержит коробку.

Direct: цена **120 000**, НДС **8 %**, комиссия **0**:

- `netRevenue` = `120000 / 1.08` = **111 111,111…**
- `grossProfit` = `net − 0 − 60016.666… − 2000` = **49 094,444…**
- `foodCostPct` = `(food / net) * 100`

Grab Food: цена **150 000**, комиссия **25 %**:

- комиссия = **37 500**
- `grossProfit` = `150000/1.08 − 37500 − 60016.666… − 2000` = **39 372,222…**

Shopee без комиссии: `complete=false`, `grossProfit=null`, issues = `["no_commission"]`.

## Потери (брутто со склада)

Тест `losses: stored on products and recipe/dish lines, gross stays the stock amount`:

- `loss_clean_pct = 26` на яблоке.
- Нетто = брутто × (1 − 0,26) при методе `clean`.
- Со склада уходит **брутто**. Нетто только для выхода порции.
- `loss_fry_pct = 100` — отказ constraint.

Проведение партии котлет в том же тесте: actual beef 2,1 кг + salt 0,02 → `total_cost` **420 200**, `output_unit_cost` **32 323,076923** на 13 шт. Карточка рецепта после этого числа не меняет.

## Черновик Agent 3 (ещё не в main)

`GASTROBAR-menu-logic`, без коммита: default источника техкарты = `reference` (= текущий `est_unit_cost`). C1–C6 остаются верны.

Дополнительно в `channelResult`:

- `markupPct = (netRevenue − totalCost) / totalCost × 100` (null если cost 0 или null)
- источники `last_lot` / `fifo_remaining` — только плановая себес, **не** `erp_consume`

Миграция черновика `20261106143000_erp_menu_cost_history.sql`: новая таблица `erp_card_revisions`, функция котировок, `erp_load_state` + часть `costSources`. Похоже additive (нет DROP каталога/партий). Не применять, пока нет коммита и повторной проверки.

## Что сверить на UI после среза

На карточке блюда с тем же составом:

1. Строка котлеты раскрывается в говядину+соль.
2. «нет цены» на коробке без `est_unit_cost`.
3. KPI продуктов / упаковки / порции / Food Cost / маржа совпадают с C2–C5 (±1 ₫ из-за `roundMoney`).
4. Пустая цена канала = цена меню.
