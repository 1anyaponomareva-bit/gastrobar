# Сценарии приёмки ERP «Меню»

Статусы: `ждёт спеки` · `ждёт логику` · `ждёт UI` · `готово` · `пройден` · `провал` · `блокер`.

Источник колонки «Откуда»: бриф родителя; текущие тесты ERP; файл спеки Agent 1 (когда появится). Поведение Poster в чек-лист попадает **только** из спеки.

Среда: `PGlite` = изолированная БД; `prod-read` = gastrotruck.org без списаний; `prod-write` = только если срез реален и запись не трогает партии/остатки.

---

## A. Вкладки, формы, меню ↔ спека

Чек-листы по вкладкам: [tabs/](tabs/). Спека Товары есть; остальное ждёт файлов Agent 1.

| ID | Сценарий | Среда | Откуда | Статус |
|----|----------|-------|--------|--------|
| A1 | Товары: колонки, поиск, фильтры, пустой/заполненный список | prod-read | спека `tovary.md` | **блокер**: UI рисует `erp_dishes`, Poster-товары — готовая перепродажа, список в аккаунте пуст |
| A2 | Товары: ⋮, столбцы, добавить/правка, обязательные поля | PGlite + UI | спека `tovary.md` | форма в UI — блюдо, не товар; ⋯ тулбара Poster не проверено |
| A3 | Тех. карты: список, форма состава, выход, потери | PGlite + UI | спека | ждёт спеки |
| A4 | Полуфабрикаты: список, карточка, связь с техкартой | PGlite + UI | спека | ждёт спеки |
| A5 | Ингредиенты: тот же `erp_products`, нет второго справочника | prod-read | бриф + спека | ждёт спеки |
| A6 | Контроль фудкоста: колонки и формулы как в спеке | prod-read | спека | ждёт спеки |
| A7 | Категории товаров и тех. карт | PGlite + UI | спека | ждёт спеки |
| A8 | Категории ингредиентов | PGlite + UI | спека | ждёт спеки |
| A9 | Цехи | PGlite + UI | спека | ждёт спеки |
| A10 | Каждая кнопка: заявленное действие **или** явная пометка «не реализовано». Нет фиктивного успеха | UI | бриф | ждёт UI |

Проход A*: открыть вкладку по спеке → сверить шапку, фильтры, колонки, пустое состояние, меню строки/столбцов, форму добавить (открыть и закрыть без записи на prod).

## E. Экспорт, печать, телефон

Эталон склада: экспорт/печать тянут **все** отфильтрованные строки (`fetchAllDocuments` + фильтр), не только текущую страницу.

| ID | Сценарий | Среда | Откуда | Статус |
|----|----------|-------|--------|--------|
| E1 | Экспорт при активном поиске/фильтре = все подходящие строки, не page size | UI | бриф + паттерн склада | черновик UI: `exportList` берёт `sorted` (все filtered) — ок, если дойдёт до коммита |
| E2 | Печать того же набора, что экспорт | UI | бриф | черновик UI: `window.print()` по текущей странице pager, не все filtered — риск провала |
| E3 | Пустой список: экспорт disabled или явная пустышка, без фейкового файла | UI | спека + паттерн склада | ждёт спеки |
| E4 | Телефон ~390: данные читаемы, действия доступны, нет растягивания всей страницы (скролл таблицы ок) | UI | бриф | ждёт UI |
| E5 | Планшет и ПК: те же вкладки, RU/EN/VN не сбрасывает форму | UI | бриф | ждёт UI |
