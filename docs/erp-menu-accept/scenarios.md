# Сценарии приёмки ERP «Меню»

Статусы: `ждёт спеки` · `ждёт логику` · `ждёт UI` · `готово` · `пройден` · `провал` · `блокер`.

Источник колонки «Откуда»: бриф родителя; текущие тесты ERP; файл спеки Agent 1. Поведение Poster в чек-лист попадает **только** из спеки (или явно помеченного наблюдения приёмки).

Среда: `PGlite` = изолированная БД; `prod-read` = gastrotruck.org без списаний; `prod-write` = только если срез реален и запись не трогает партии/остатки.

---

Проход A*: открыть вкладку по спеке → шапка, фильтры, колонки, пустое, меню, форму добавить (на prod без записи).
