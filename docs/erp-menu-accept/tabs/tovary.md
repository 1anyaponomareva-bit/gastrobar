# Приёмка: Товары

Спека Agent 1: `GASTROBAR-menu-spec/docs/erp-menu-poster/tovary.md` (файл есть, **коммита нет**). Скрин: `shots/tovary-list-empty-gastrobar.png`.

## Смысл вкладки (блокер среза)

Poster **Товары** = купили готовым и продаёте без обработки (лимонад в бутылке, шоколад). **Не** участвуют в приготовлении блюд. «подтверждено документацией»

В этом аккаунте список **пуст во всех 4 заведениях**. Меню живёт в тех. картах. «увидел в интерфейсе»

Черновик UI `5a341a0` кладёт сюда `erp_dishes` (те же строки, что «Тех. карты»). Это **не** Poster-Товары. Публиковать вкладку как «Товары» нельзя: на сайте появятся блюда там, где у Poster 0 товаров.

Ближе по смыслу: `erp_products` с типом, который не идёт в рецепт (готовая перепродажа). Отдельного типа «товар Poster» в ERP нет. Не выдумывать до контракта Agent 3 после этой спеки.

## Создать / открыть / сохранить

Не гонять на prod, пока сущность не та. На PGlite после смены модели: форма товара (не блюда) → сохранить → F5 те же поля; склад не двигается.

## Экспорт / печать / телефон

- Экспорт: все отфильтрованные (в черновике `sorted`) — повторить, когда список будет товарами.
- Печать: должна быть как Chrome print **полного** отфильтрованного набора; сейчас pager.
- ~390: вкладки Меню в `MenuMobileNav`.

## Не требовать (спека: не проверено)

Полный хвост «Столбцы», +Фильтр, ⋯ тулбара, валидация Сохранить, форма Ред., модификации UI, налог dropdown, Restore из корзины.
