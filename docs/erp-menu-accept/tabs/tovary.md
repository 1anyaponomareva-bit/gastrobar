# Приёмка: Товары

Спека Agent 1: `GASTROBAR-menu-spec/docs/erp-menu-poster/tovary.md` (файл есть, **коммита нет**). Скрин: `shots/tovary-list-empty-gastrobar.png`.

## Смысл вкладки

Poster **Товары** = купили готовым и продаёте без обработки. **Не** участвуют в приготовлении блюд. «подтверждено документацией»

В этом аккаунте список **пуст во всех 4 заведениях**. Меню живёт в тех. картах. «увидел в интерфейсе»

`cc6d30d` (в `origin/main` `490d1dd`): вкладка фильтрует `erp_products` с `type === "finished"`. `/erp/products` — полный каталог (не редирект в ингредиенты).

На ERP вкладке Товары ожидаем 0 finished, пока их не заведут.

## Создать / открыть / сохранить

На PGlite: форма `type=finished` → сохранить → F5; склад не двигается. На prod не заводим тестовые товары без `ACCEPT-MENU-…`.

## Не требовать (спека: не проверено)

Хвост «Столбцы» после Наценка/Налог, валидация Сохранить, форма Ред., модификации UI, Restore из корзины (кнопку на пустой корзине не видели).
