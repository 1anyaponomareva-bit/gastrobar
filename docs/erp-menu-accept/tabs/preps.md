# Приёмка: Полуфабрикаты

Спека Agent 1: `GASTROBAR-menu-spec/docs/erp-menu-poster/polufabrikaty.md` (файл есть, **коммита нет**). Список Poster: **39**; поиск `SAUCE` → **7**. Форма Добавить открыта без Сохранить. Форму Ред. живого п/ф не открывали.

Смысл: заготовки для тех. карт, на кассе не продаются, учёт в кг. В ERP: `erp_products.type === "semi_finished"` + `erp_recipes`. Партии — склад (`/erp/preps/batches`), не эта карточка.

Черновик UI на `origin/main`: `/erp/menu/preps` = `MenuPrepsList`. `/erp/preps` редиректит сюда.

## Создать / открыть / сохранить (только PGlite)

- Новая заготовка + рецепт → сохранить → активировать → правка даёт новую версию (B5 **пройден**).
- Цикл рецепта — отказ (D2/D3 **пройден**).
- На prod не заводим тестовые п/ф без имени `ACCEPT-MENU-…`.

## Не требовать (спека: не проверено)

Форма Ред. живого соуса, меню ⋯ строки, панель Состав, заполненная таблица использования, 📎 брутто/нетто, метод приготовления, экспорт/печать формат, вложенность п/ф в п/ф.
