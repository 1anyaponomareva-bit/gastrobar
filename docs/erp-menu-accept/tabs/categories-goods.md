# Приёмка: Категории товаров и тех. карт

Спека Agent 1: `GASTROBAR-menu-spec/docs/erp-menu-poster/kategorii-tovarov.md` (файл есть, **коммита нет**). Саму вкладку Poster **не открывали**. Имена категорий — из формы товара (без Сохранить).

Смысл: дерево **кассы**. Корень **Главный экран**. Удаление категории тащит товары и тех. карты в корзину **30 дней**. Не путать с категориями ингредиентов.

ERP: `/erp/menu/categories` = тот же `erp_categories`, что и ингредиенты. Подсказка на экране это говорит честно.

## Чек-лист ↔ спека

| # | Требование спеки | UI `490d1dd` | Приёмка |
|---|------------------|--------------|---------|
| 1 | Отдельное дерево кассы vs категории ингредиентов | один `erp_categories`, два URL | **зазор данных**; UI не врёт |
| 2 | Default на форме товара/техкарты: Главный экран | `defaultDishCategoryId` ищет «главн/main screen» | частично |
| 3 | Имена из формы товара (неполный список) | справочник ERP, не Poster-имена | не копировать Poster-меню в каталог |
| 4 | Удаление категории + позиций, 30 дней | архив категории RefList | **зазор** |
| 5 | Налог родительской категории | в ERP нет налога категории | **ждёт контракт** |
| 6 | Фото/цвет иконки 168×126 | нет | не требовать |
| 7 | Существующие `category_id` продуктов целы | не truncate | F1/F2 |

Полуфабрикаты поля категории не имеют (спека п/ф) — не вешать кассовое дерево на п/ф.
