# Приёмка: Ингредиенты

Спека Agent 1: `GASTROBAR-menu-spec/docs/erp-menu-poster/ingredienty.md` (файл есть, **коммита нет**). В файле спеки список вкладки **не открывали**. Документация: сырьё для техкарт/п/ф; себестоимость средневзвешенная; в карточке вручную не задают; **восстановить удалённый нельзя**.

Жёсткое правило брифа: **не** второй справочник. Это те же `erp_products` (`ingredient`, плюс упаковка/расходники фильтром).

ERP на `origin/main`: `/erp/menu/ingredients` = `MenuIngredientsPage`. Полный каталог остаётся на `/erp/products`.

## Список Poster (наблюдение приёмки 2026-11-06 16:28)

В Chrome владельца на `https://gastrobar.joinposter.com/manage/ingredients` был заполненный список. **Сохранить / Удалить / Добавить не жали.** Это не файл спеки Agent 1; в чек-лист можно брать только то, что видно на скрине:

- Заголовок **Ингредиенты 297**
- Тулбар: **Столбцы**, **Экспорт**, **Импорт**, **Печать**, зелёная **Добавить**. Корзины в тулбаре **не было**
- Фильтры: **Быстрый поиск**, **Категория**, **Ед. измерения** (шт / кг / л), **+ Фильтр**. Нет Цех / Заведение
- Колонки: Название, Категория▲, Ед. измерения, Потери, Остатки на складах, Себестоимость, Сумма остатков; справа **Детали**, **Ред.**, **⋯**
- Себестоимость видимых строк **0,00 ₫**; остатки **0,000 л**
- **Детали** (раскрытая строка COGNAC): блок «Используется в тех. картах:» колонки Название, Брутто, Нетто, Цена ₫ (пример 50,00 мл / 50,00 мл / 0,00)

Форму Добавить спека описывает по docs (название, категория ингредиентов, единица, Дополнительно = % потерь). В этой сессии приёмки форму не заполняли.
