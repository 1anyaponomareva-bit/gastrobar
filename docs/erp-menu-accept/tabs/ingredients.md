# Приёмка: Ингредиенты

Спека Agent 1: `GASTROBAR-menu-spec/docs/erp-menu-poster/ingredienty.md` (список 297, Столбцы, фильтры, Добавить без Сохранить, Детали COGNAC).

Жёсткое правило: **не** второй справочник. Это те же `erp_products`. Классификация — **категория** и **поставщик фасовки** (`erp_product_packs.supplier_id`), колонки/фильтра **Тип нет**. Поставщика оставляем по запросу кухни, даже если в Poster этой колонки нет.

ERP: `/erp/menu/ingredients` = `MenuIngredientsPage`. Полный каталог остаётся на `/erp/products` (127). 297 строк Poster **не** импортировали.

## Список Poster (спека + скрин 2026-11-06)

- Заголовок **Ингредиенты 297**
- Тулбар: **Столбцы**, **Экспорт**, **Импорт**, **Печать**, зелёная **Добавить**. Корзины нет
- Фильтры: **Быстрый поиск**, **Категория**, **Ед. измерения** (шт. / кг / л), **+ Фильтр**. Нет Цех / Заведение
- Колонки по умолчанию: Название, Категория, Ед. измерения, Потери, Остатки на складах, Себестоимость, Сумма остатков; справа **Детали**, **Ред.**, **⋯**
- В «Столбцы» ещё скрытые: Штрихкод, Вес штучного ингредиента
- Потери: пять % (очистка / варка / жарка / тушение / запекание) или **—**
- **Детали**: «Используется в тех. картах:» Название, Брутто, Нетто, Цена ₫

## Чек-лист

| # | Poster | ERP после этого прогона | Источник |
|---|--------|-------------------------|----------|
| 1 | Название | да | `erp_products` |
| 2 | Категория | да | `erp_categories` |
| 3 | Ед. измерения | да | `base_unit` |
| 4 | Потери | да; все null → **—**, не 0 | `loss_*_pct` |
| 5 | Остатки на складах | да, read-only | `erp_stock` / `stockView` |
| 6 | Себестоимость | да; неизвестная → **—**, не 0 | средняя партий или `est_unit_cost` |
| 7 | Сумма остатков | да; неполная → **—** | `stockValue` (`complete=false` → null) |
| 8 | Детали / Ред. / ⋯ | да | техкарты `erp_dishes`, п/ф `erp_recipes`; Ред. = карточка продукта; ⋯ = архив (склад не двигает) |
| 9 | Штрихкод | колонка в «Столбцы», значение **—** | поля в каталоге нет |
| 10 | Вес штучного | скрыта по умолчанию | `unit_weight_kg` или **—** |
| 11 | Поставщик | **да** (не Poster, запрос кухни) | `erp_product_packs.supplier_id` |

| 14 | Импорт | кнопка тулбара, «не реализовано» | не фейковый успех, 297 не грузим |
| 15 | `/erp/products` | полный каталог | не редирект |
