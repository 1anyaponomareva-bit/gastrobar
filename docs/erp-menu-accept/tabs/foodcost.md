# Приёмка: Контроль фудкоста

Спека Agent 1: `GASTROBAR-menu-spec/docs/erp-menu-poster/foodcost.md` (файл есть, **коммита нет**). Это **Postie AI**, не светлая таблица Меню. Отчёт **не открывали** (лимит 0/20 действий; не жали Начать / Принять / смену цен).

Классическая формула Poster «подтверждено документацией»: фудкост = себестоимость / **итоговая цена** × 100%. Наценка зависит от налога (три формулы в спеке Товары/фудкост).

ERP на `origin/main`: `/erp/menu/foodcost` = `MenuFoodcostPage` по `erp_dishes`. Это **не** клон Postie.

## Чек-лист ↔ спека
