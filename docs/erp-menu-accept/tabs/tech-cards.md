# Приёмка: Тех. карты

Спека Agent 1: `GASTROBAR-menu-spec/docs/erp-menu-poster/tech-karty.md` (файл есть, **коммита нет**). Список Poster: **111** при Заведение GASTROBAR; корзина **28**. Форма Ред. CHEESEBURGER `511` открыта без Сохранить. Форму Добавить не открывали.

Смысл: тех. карта = блюдо/напиток с рецептом. В ERP это `erp_dishes` + линии + цены каналов. Не путать с Товарами (готовая перепродажа, `type=finished`).

Черновик UI после `cc6d30d` / merge `d6c5269`: вкладка «Тех. карты» = `erp_dishes`. Товары больше не дублируют этот список.

## Создать / открыть / сохранить (только PGlite)

- Новое блюдо → сохранить → URL с id → F5 те же поля.
- Правка состава и цены канала → открыть снова.
- Сохранение **не** меняет `erp_movements` / `erp_lots`.

## Не требовать (спека: не проверено)

Форма Добавить Poster, фильтры Категория/Цех/+Фильтр на списке, хвост «Столбцы», импорт, печать формы «Распечатать», ⋯ Копировать/Скрыть/Удалить, модификаторы, скрепка брутто/нетто, тумблеры заведений.
