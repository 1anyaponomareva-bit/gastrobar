## Создать / открыть / сохранить (только PGlite)

- Новое блюдо → сохранить → URL с id → F5.
- Правка состава и цены канала → открыть снова.
- Сохранение **не** меняет `erp_movements` / `erp_lots`.

## Не требовать (спека: не проверено)

Фильтры Категория/Цех/+Фильтр на списке Poster, импорт UI, «Распечатать» на форме, ⋯ Копировать/Скрыть, модификаторы, 📎, тумблеры заведений, inline Цена.
