# Poster: Инвентаризации

Просмотрено 5 ноября 2026 на https://gastrobar.joinposter.com/manage/calculations/inventory (светлая тема). Видео YouTube не смотрели.

## Список

- Шапка: «Инвентаризации» + число документов справа от заголовка.
- Справа: Столбцы, Экспорт, Печать, период, Добавить.
- Инфо-блок: «Проведите инвентаризацию» + текст про полную проверку минимум каждые 2 месяца + «► Смотреть видео».
- Фильтры: «Быстрый поиск», «Склад», «+ Фильтр».
- Колонки (все есть в меню «Столбцы», лишних нет): Склад; Начало периода; Дата и время проведения; Тип; Результат; Статус.
- Меню столбцов: заголовок «Отображать столбцы:», затем шесть колонок, «Вернуть по умолчанию».
- Период: Сегодня; Вчера; Последние 7 дней; Последние 30 дней; текущий месяц; прошлый месяц; За все время; календарь + «Применить».
- Экспорт при 0 документов: кнопка disabled, меню нет.
- Печать: отдельного меню нет (не disabled на пустом списке). Состав печати не подтверждён — в ERP печатаем видимую таблицу.
- «+ Фильтр» открывает «Показать только те, в которых:» и searchable select. Список полей select не раскрылся за 2 попытки. В мобильном блоке фильтров подтверждены: Склад; Тип (Полная / Частичная); Статус (Открытая / Проведённая / На редактировании).
- Пустое состояние внутри области списка: «Здесь будут инвентаризации» + текст про склады и расхождения. Шапка, фильтры и заголовки таблицы остаются.

## Форма «Добавить»

URL: `/manage/calculations/inventory/form`

- Склад (обязателен; «Сохранить» disabled без склада).
- Проверка остатков: «Задним числом» / «Временем проведения» (disabled до выбора склада).
- Тип инвентаризации: «Полная» / «Частичная» (disabled до выбора склада).
- Подсказка: «Выберите склад, на котором хотите проверить остатки продуктов».
- Дата/время после «Задним числом» и выбор продуктов после «Частичная» не просмотрены: переключатели недоступны, пока не выбран склад; клик по combobox склада перехватила вёрстка. По документации: дата/время фактических остатков; для частичной — поиск категорий/продуктов с флажками.

## Документация (knowledge-base)

Полная: https://knowledge-base.joinposter.com/ru/how-to-run-an-inventory-check
Частичная: https://knowledge-base.joinposter.com/ru/how-to-run-a-partial-inventory-check

Правила Poster (не переносим вслепую на нашу модель):

1. В полную и частичную входят только позиции с движением за период; без движения — не показываются.
2. Период продукта: от его предыдущей инвентаризации на этом складе до даты текущей.
3. Техкарты / полуфабрикаты / производства считаются на отдельных вкладках; Poster пересчитывает их в ингредиенты. В ERP нельзя одновременно учитывать готовое блюдо и его ингредиенты.
4. Полная проверка за период закрывает открытые частичные на том же складе.
5. Исправление: «Открыть период и редактировать»; на складе одновременно одна инвентаризация на редактировании.
6. Удалить можно только последнюю инвентаризацию склада.
7. Операции после последней проведённой — без открытия периода; до неё — только после открытия инвентаризации, в период которой они входят.
8. Экспорт документа: XLS из открытой инвентаризации.

## Неподтверждённые детали

- Точный список полей «+ Фильтр» в desktop select.
- Состав и формат экспорта списка (XLS vs CSV); в ERP список выгружает CSV всей отфильтрованной выборки.
- Меню и состав печати списка.
- UI выбора даты после «Задним числом» и picker частичной проверки после выбора склада.
