## Причины задержки склада

1. **Анонимный `/erp/stock`**: «Загрузка…» 1.5–2.5 с, пока `/api/erp/state` тянет весь каталог и отвечает 401.
2. **Регион**: UI во Вьетнаме, serverless в `iad1`. Пустой ping уже ~0.3 с. Каждый API после логина добавляет ещё 0.5–1 с до базы.
3. **Водопад после входа**: `ErpShell` ждёт полный state (включая recipes/dishes), *потом* монтирует вкладку, *потом* `useDocuments` бьёт `/api/erp/documents`. Это не в этом diff: нужен `ErpShell`.
4. **~16 PostgREST** на state. Комментарий ba8d8a7 «one database round trip» был неверен. При лимите соединений это 2–3 волны; на проде сейчас ближе к 1 волне, но патчи `loadState(['stock','products'])` всё ещё 2 поездки.
5. **Поставки**: строки грузились чанками **по очереди**; списания — `Promise.all`.

Не в этой полосе: вёрстка списаний, печать/экспорт, FIFO, проведение инвентаризации, счета.

## Что исправлено в ветке

1. `readAsAdmin`: нет cookie — **401 без БД**. Анонимный вход должен стать как ping (~0.3 с до формы), не 1.5–2.5 с. Залогиненный путь по-прежнему auth∥db.
2. SQL `erp_load_state` + вызов из `loadState` с откатом, если функции нет (кэш промаха на инстанс).
3. `/api/erp/receipts`: чанки строк параллельно, как у writeoffs.

## Издателю

Миграция совместимая (только функция). Применить **до или вместе** с кодом, иначе первый запрос инстанса сделает неудачный RPC и откатится.

Файлы, которые эта ветка **не** трогала и которые нужны для большего выигрыша:

- `src/lib/erp/localDb.ts` и `scripts/erp/testDb.ts` — добавить `20261106011500_erp_speed_load_state.sql` в список миграций (иначе PGlite/тесты живут на fallback).
- `src/components/erp/ErpShell.tsx` — начать `/api/erp/documents` вместе со state **или** сначала `STOCK_SHELL_PARTS` из `stateLoader.ts`, recipes/dishes догрузить фоном.
- `src/components/erp/docs.tsx` / `src/lib/erp/types.ts` — только если документы вшивают в state.

Инфра (не код): колокация Vercel с регионом Supabase. С `iad1` один select уже 0.5–1 с.

## Не замерено

- Холодный вход **с сессией** (openMs, первый экран остатков/поставок глазами).
- Save/post, карточка «Скорость связи» под админом.
- Реальный размер JSON state на проде.
- Регион проекта Supabase.
- Инвентаризация, проведение, FIFO, печать, мобильная вёрстка списаний.
- После выкладки этой ветки: повтор 401 `/api/erp/state` (должен быть без `db;dur`).
